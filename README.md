# Telegram Group Management Bot

একটি সম্পূর্ণ Telegram গ্রুপ ম্যানেজমেন্ট বট!

## Features:
- Welcome messages
- Ban/Kick/Mute users
- Warning system
- User info
- Group rules
- Pin messages

## Commands:
- /help - সব কমান্ড দেখুন
- /ban - ব্যান করুন
- /kick - কিক করুন
- /mute - মিউট করুন
- /warn - সতর্কতা দিন

## Setup:
1. BotFather থেকে TOKEN নিন
2. GitHub এ আপলোড করুন
3. Render এ deploy করুন
4. গ্রুপে বট যোগ করুন
